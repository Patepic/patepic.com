# 🎮 Patepic.com

> Game reviews from a gamer who actually plays them.

A personal website for game reviews, built and run by **Patepic**, VTuber, gamer, and your new favorite gaming critic.

---

## 🕹️ About

Honest game reviews covering everything from indie gems to AAA blockbusters. No sponsored opinions, no fluff, just real takes on real games.

---

## ✨ Features

- 🎮 **Game Reviews** In-depth reviews across genres and platforms
- 🔍 **Browse & Filter** Find reviews by genre, platform, or rating
- 📺 **VTuber Corner** Patepic's streaming world, all in one place
